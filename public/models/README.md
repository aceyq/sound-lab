# Pose model

`pose_landmarker_lite.task` is Google's MediaPipe Pose Landmarker (lite, float16, version 1), downloaded from
https://storage.googleapis.com/mediapipe-models/pose_landmarker/pose_landmarker_lite/float16/1/pose_landmarker_lite.task
and served by this site, so the Pose Sound Map works without a CDN. It is distributed by Google under the Apache License 2.0
(see the MediaPipe model card: https://ai.google.dev/edge/mediapipe/solutions/vision/pose_landmarker).
